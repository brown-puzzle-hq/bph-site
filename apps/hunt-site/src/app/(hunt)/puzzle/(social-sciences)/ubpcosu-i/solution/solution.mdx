**Dictionary and Grammar Guide**

**Grammar:**

Language works in OSV sentence structure\! That means that objects come first, the subjects, then verbs. Example:

_eptosu ostite obole._ \= Mangoes men hate.

This language is very conjugated. Here is how each part of speech is conjugated:

**Question Signifiers:**  
how many: tete

**Dictionary:**

These are the roots of each word:

st // person  
nn // horse

**PUZZLE SOLUTION**

We can translate the questions to

| _kiki ostepi oboka tete?_       | How many women are there?        |
| :------------------------------ | :------------------------------- |
| _kiki ostosu donku oboka tete?_ | How many brave people are there? |
| _kiki ostite obono tete?_       | How many men love?               |
| _kiki okikiosu oboka tete?_     | How many questions are there?    |

Answering these by finding the appropriate counts over the flavor text yields **4 3 2 5**

We can translate the last phrase to

| _estite bespe ultosu usile._ | The world hates sly men. |
| :--------------------------- | :----------------------- |

Which, indexing over each word, results in the final answer of

_est**i**te be**s**pe u**l**tosu usil**e**._

or ISLE.
