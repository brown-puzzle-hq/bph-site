The treble clef represents a bijection from notes to letters. The four clefs with crossword clues each represent a permutation of the alphabet, with each letter mapping uniquely to another letter. Each of these is composed with treble clef, collectively mapping notes to letters (using \#s and ♭s placed as in treble clef, due to composition with treble clef).

The crossword clues for the first five clefs are:

| Crossword Clue                  | Solution                   |
| :------------------------------ | :------------------------- |
| The English Language            | ABCDEFGHIJKLMNOPQRSTUVWXYZ |
| Like the second half of a scale | DESCENDING                 |
| Circle of \_\_\_\_              | FIFTHS                     |
| Numerical Pitch                 | FREQUENCY                  |
| Portable Piano                  | KEYBOARD                   |

Each of these clues a permutation of the alphabet:

- English: Assign letters to notes sequentially, with A first and Z last.
- DESCENDING: Assign letters in reverse order, with Z first and A last.
- FIFTHS: Assign letters by jumping in fifths, i.e. A first, A+5=F second, F+5=K third, etc.
- FREQUENCY: Using Cornell as the canonical source, the frequency of letters in English text, assigning highest frequency letters first.
- KEYBOARD: Assign letters via the QWERTY keyboard in reading order.
