Solvers should rotate the wheel until expletives (with one missing letter each) can be read from the center out. Exclamation points mark the end of the expletives.

They can then extract the missing letters in clockwise order, as shown:

| Expletive | Missing letter |
| --------- | -------------- |
| \*HUCKS\! | S |
| HOLY CO\*\!| W |
| H\*CK\! | E |
| CR\*P\! | A |
| \*ATS\! | R |
| FR\*CK\! | I |
| DAR\*\! | N |
| FUD\*E\! | G |

Reading these letters in order spells the answer, **SWEARING**.
