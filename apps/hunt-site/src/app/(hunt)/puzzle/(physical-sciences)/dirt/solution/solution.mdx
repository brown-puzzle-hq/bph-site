This puzzle involves dirt. Specifically, it involves identifying where bags of dirt sit on the soil identification chart: each bag contains a different proportion of clay, silt, and loam. Specifically, each bag contains either 0%, 33%, 66%, or 100% of each, for 10 unique points on the soil identification chart arranged in a triangle pattern.

After identifying these proportions, solvers can use this information to arrange the 10 triangle pieces into a larger triangle grid as provided in the puzzle.

<img src={image1.src} alt="Image 1" />

Similarly, solvers can use the crossword clues to fill out the triangular crossword grid, with words filling in unshaded triangles in a continuous line. The answers to the clues are as follows:

| Clue (↘)                           | Answer       |
| :---------------------------------- | :----------- |
| News host                           | ANCHORPERSON |
| Underskirt                          | PETTICOAT    |
| Small coin                          | NICKEL       |
| Campaigned for office               | RAN          |
| **Clue (→)**                        |              |
| Ltd.                                | INC          |
| Rock from space                     | METEOR       |
| Yogi Bear, Rat, and Mole, for three | PICNICKER    |
| Annulment                           | CANCELLATION |
